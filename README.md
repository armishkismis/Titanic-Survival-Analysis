# Titanic Data Analysis Project

## Overview

This project analyzes the famous Titanic dataset to identify the key factors that influenced passenger survival. The project includes data cleaning, feature engineering, exploratory data analysis (EDA), and visualizations using Python.

---

## Objectives

- Clean raw Titanic dataset
- Handle missing values
- Perform feature engineering
- Explore passenger survival patterns
- Create meaningful visualizations

---

## Dataset

Source:
Kaggle Titanic Dataset

Dataset contains:

- Passenger Class
- Age
- Gender
- Fare
- Embarked Port
- Family Information
- Survival Status

---

## Tools & Libraries

- Python
- Pandas
- NumPy
- Matplotlib
- VS Code / Jupyter Notebook

---

## Data Cleaning

Performed the following:

- Removed unnecessary columns
- Filled missing Age values
- Filled missing Embarked values
- Filled Fare values
- Converted categorical variables
- Created new features:
  - FamilySize
  - IsAlone
  - Title

---

## Exploratory Data Analysis

Analysis includes:

- Survival Rate by Gender
- Survival Rate by Passenger Class
- Age Distribution
- Survival by Family Size

---

## Visualizations

- Bar Charts
- Histogram
- Survival Analysis Graphs

---

## Key Insights

- Female passengers had higher survival rates.
- First-class passengers had better survival chances.
- Family size affected survival probability.
- Passenger class and gender were major factors.
